# crazy-water-world-redeem

一、这是什么

一个 WorkBuddy 技能。你把礼包码清单交给它，它用你本人的微信游戏登录状态逐个
提交，最后告诉你每个码是成功、已过期、还是已被用过。

全程在你自己的电脑上运行，数据只在 127.0.0.1 内流转，不上传到任何服务器。

二、开箱前先看：这几条不满足就别装了

1. Windows 10 / 11。
2. Node.js 22.15 或更高（官网下 LTS 版，一路下一步即可）。
3. 微信 PC 客户端，且能在微信里打开「疯狂水世界」这个小游戏。
4. 微信不能以管理员身份运行。

第 4 条最容易被忽略。平时习惯"右键 → 以管理员身份运行"的，改成普通双击，
否则读不到小游戏进程内存，采集一定失败。

三、怎么装

1. 复制项目地址发送给workbuddy，让他下载代码并安装 crazy-water-world-redeem skill。

2. 关掉 WorkBuddy，重新打开。

3. 新开一个对话，说：「用 crazy-water-world-redeem 检查一下环境」
   能回出 Node 版本和微信小程序进程数量，就算装好了。

四、怎么用

先在微信里打开「疯狂水世界」，进到游戏主界面。不用一直挂着，但必须真的进过一次。

然后把码清单发给 WorkBuddy，说「帮我批量兑换」。它会：

  1. 采集登录状态 —— 显示账号尾号，你确认是不是你自己
  2. 预览清单 —— 显示待提交几个、被拦截几个、以及完整码列表
                   这一步不连接游戏、不消耗任何码
  3. 等你确认
  4. 执行 —— 给出结果汇总

结果里的 success 只代表"服务器返回了奖励"。具体到没到账，请自己到游戏邮件或
背包核对，工具没法替你验收。

五、必须先知道的风险

· 真实兑换不可撤回。提交出去的请求收不回来，所以务必先看清单再确认。
· 兑换期间会把你的游戏顶下线。服务端一个账号只保留一条会话，工具一登录，
  你正在玩的客户端就会提示"已在其他处登录"。这不是故障，是必然结果。
· 这是非官方协议实现，不是游戏官方功能。存在账号风险，请自行判断是否使用。
· 礼包码是全服共享、次数有限的资源，别人用掉就没了。多个人跑同一份清单，
  只会更快耗尽，不会让谁多拿。

如果上面任何一条你不能接受，请不要使用。

六、别人的登录状态不能通用

登录凭据和账号、设备绑定，而且每次登录都会换新的。所以每个人必须在自己电脑上、
自己的微信里，自己采集一次。别人给你采集好的快照是无效的。

七、卸载

删掉 C:\Users\<你的用户名>\.workbuddy\skills\crazy-water-world-redeem\ 整个目录即可。
注意 scripts\data\ 里是你的兑换记录和登录快照，会一起被删掉。
